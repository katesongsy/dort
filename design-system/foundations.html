Give each piece of text one job. Keep that job legible without color and at small terminal sizes.

Text roles

Use terminal theme colors by role, not by fixed RGB value. Reserve status colors for a change in state or a condition that needs attention.

Section heading
Cyan, bold. Names a section of the interface or a group of fields.
Snapshot
Default color, bold. Identifies a field but does not compete with a heading.
2026-06-18
Default color and weight. Shows the value. Keep long paths and command text readable.
Finished
Green. Marks completed work, never work that is only ready.
Warning
Yellow. Names a condition to consider before proceeding.
Blocker
Red. Names a condition that prevents the action. Give a next step.

Without color

Keep status words visible. Distinguish headings with weight and underline, labels with weight, and values with plain text. Mark the selected row with reverse video or a visible marker. Name the focused pane in text.

Terminal cells

  • Measure display cells, not bytes or Unicode code points. Keep joined characters intact when you wrap or truncate.
  • Shorten list previews when space is tight. Keep the full text available in the detail reader or review.
  • Wrap prose and let long values and lists scroll in the pane that owns them. Keep the action area in place. Show when more content is available and how to reach it.
