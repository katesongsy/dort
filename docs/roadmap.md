# Roadmap

Dort is pre-1.0. No dates are promised. Each feature ships for CLI and TUI together.

## Done

Local repositories, file links and recovery, Git inspection, manifest checks, and Homebrew/npm tool checks and installs on macOS, Linux and WSL.

Generated files with literal or Jinja templates, explicit inputs, drift detection, and reviewed deployment and updates.

## Next

### Environments

Persistent profile controls with clear semantics, cloning without deployment, one plan covering files and tools, dependency-ordered changes and resume after failure.

### Secrets

Age keys and recipients, encrypted backups before writes, redacted workflows, and protected deployment and editing.

### Portability and sync

A safe model for live links versus Git references, incoming/conflict review, approved reference updates, and explicit hook/filter policy.

### 1.0

Wider host and package-manager coverage, migration rules, security review, and release automation.

## Not planned

Automatic rollback, silent upgrades, or writes without review.
